Step-Level Feedback Distillation

Teaching a small, answer-blind model to catch reasoning mistakes step-by-step — by distilling a stronger teacher that's allowed to peek at the answer.

🚀 Start here

🧩 What we're building

A small ground-truth-free student that reads a math solution and flags which step the reasoning first goes wrong — not just whether the final answer is right. It learns this from a stronger privileged teacher that sees the reference solution while labeling.

🔄 Why it was revived

The earlier version stalled (CLEAR + TinyLlama; weak scorers, gibberish on math). Revived June 2026 with a shift to step-level reasoning evaluation over final-answer accuracy. Target: a publishable result for COLM/AAAI/workshop — flexible; quality over the date.

📍 Where we are today

Phase-0 teacher gate complete. Teacher, dataset, and privilege form chosen by data; core claim validated at N=150. Cross-teacher replication (Qwen-27B) pending restart after a run crash. Next: fix student trainer + hand labeling to GPU.

🎯 The research question

Does distilling a teacher's step-level score + natural-language critique — and its privileged (answer-aware) judgment — into a small answer-blind student make it better at catching reasoning-step errors? Finding so far: privilege helps, but only when the problem is hard and the privilege is rich (a worked solution, not a bare answer).

★ Headline result — privilege × difficulty

Green badge = privilege helped. Privilege buys signal only where the teacher can't already self-verify, and only when given a full worked solution (not just an answer).

How to read the three panels together: The N=50 MATH preliminary (middle) shows a stronger solution gap than the N=150 confirmed run — both point the same direction. The N=150 number is the conservative, paper-ready estimate. The interesting wrinkle is that the bare answer also gains at N=50 (+0.10) but flatlines at N=150 (±0.00) — possibly a small-N artifact worth a brief note. The key claim is stable: rich privilege (full solution) helps on hard problems; a bare answer does not.

Why this matters

Gemma and Qwen are different model families trained on different data. If the privilege×difficulty pattern holds for Qwen-27B too, it's not a Gemma artifact — it's a property of step-level feedback under difficulty.

The bakeoff F1 (0.873) suggests Qwen-27B is a capable teacher, so the privilege signal should be available — we just haven't measured the gap yet. ETA: pending oMLX run (~2-3 hrs).
