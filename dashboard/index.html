Step-Level Feedback Distillation

Teaching a small, answer-blind model to catch reasoning mistakes step-by-step — by distilling a stronger teacher that's allowed to peek at the answer.

Project overview

What we're building

A small ground-truth-free student that reads a math solution and flags which step the reasoning first goes wrong — not just whether the final answer is right. It learns this from a stronger privileged teacher that sees the reference solution while labeling.

Why it was revived

The earlier version stalled (CLEAR + TinyLlama; weak scorers, gibberish on math). Revived June 2026 with a shift to step-level reasoning evaluation over final-answer accuracy. Target: a publishable result for the COLM workshop (~early July) — flexible; quality over the date.

Where we are today

First full GPU run is in (Saksham — probe + student ablation + best-of-N, on the gemma-2-9b-it fallback). Phase 1 probe replicates (privilege gap holds). But the Phase 2 student headline is on hold pending a metric fix: the reported privilege-transfer gap (F1 0.037 → 0.197) turned out to be a fixed-threshold artifact, not capability — caught via the tell that first_error_acc was identical across cells. Eval is now threshold-free (ROC/PR-AUC); we re-score the existing checkpoints, switch to the canonical teacher, then scale. Phase 3 prelim: PRM re-rank 32.0 vs majority-vote 32.5 — not a win yet.

The research question

Does distilling a teacher's step-level score + natural-language critique — and its privileged (answer-aware) judgment — into a small answer-blind student make it better at catching reasoning-step errors? Finding: privilege has a tractability sweet spot — it helps only where the teacher both needs the reference (can't self-verify) and can use it; and only rich privilege works (a worked solution, not a bare answer).

Reading across panels: The N=50 preliminary shows a stronger solution gap (+0.13) than the definitive N=400 run (+0.05, 95% CI [0.01, 0.09] — significant) — both point the same direction; N=400 is the paper headline. Within MATH the gap peaks at the intermediate levels (L3 +0.11) and collapses at L1 (−0.13, too easy) and the hardest tail — the sweet spot replicates inside the dataset. The bare-answer row is inert (+0.00, measured at N=150). Core claim is stable: rich privilege (full worked solution) helps on hard-but-tractable problems; a bare answer does not.
Mechanism — why privilege helps (N=400): the gain is a rescue of self-verification failures, not a raw difficulty effect. Gate 1 (needs help): of 227 error problems, the no-GT teacher missed 89 → +solution rescues 29 (33%); of the 138 it already caught, +solution breaks only 17 (12%) — the benefit concentrates exactly where the teacher can't self-verify. Gate 2 (can use): rescue rate falls monotonically with reference length (short 0.37 → mid 0.33 → long 0.28) — the reference only helps when the teacher can follow it. The moderator is self-verification-failure × tractability.

Why this matters

If the privilege×difficulty pattern holds for Qwen-27B too, it's not a Gemma artifact — it's a property of step-level feedback under difficulty. Bakeoff F1 (0.873) shows Qwen-27B is a capable teacher. Unblocks Saksham once confirmed.
